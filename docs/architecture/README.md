# Architecture Docs Menu

Use this page as the entry point for architecture documents.

## Which file to read

- `system_overview.md`  
  High-level architecture and design goals. Start here for context.

- `workflow_technical.md`  
  Technical execution flow, flowchart, optional branches, and I/O examples.

- `workflow_non_technical.md`  
  Plain-English workflow for non-technical readers and stakeholder communication.

- `agents.md`  
  Agent list, responsibilities, and expected I/O boundaries per agent.

- `orchestrator.md`  
  Orchestrator responsibilities, control logic, and conflict resolution role.

- `output_schema.md`  
  Canonical output structure and field expectations for implementation alignment.

- `scope_and_roles.md`  
  Team ownership model, scope boundaries, and collaboration rules.

## Suggested reading order

1. `system_overview.md`
2. `workflow_non_technical.md` (or `workflow_technical.md` for engineers)
3. `agents.md`
4. `orchestrator.md`
5. `output_schema.md`
6. `scope_and_roles.md`
